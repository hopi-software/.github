## Explora nuestros proyectos

En nuestros repositorios públicos compartimos código y herramientas que
puedes explorar, probar y adaptar según la licencia de cada proyecto.

- [Ver los repositorios de Hopi](https://github.com/orgs/hopi-software/repositories)
- [Conocer Hopi](https://hopi.cl)

## Participa

¿Encontraste un error o tienes una idea? Abre un issue en el repositorio
del proyecto e incluye los pasos para reproducir el problema o un ejemplo
de lo que te gustaría mejorar.

Si quieres aportar código, revisa primero el README y la guía de
contribución del repositorio, si está disponible.
